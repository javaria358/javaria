Student Learning Management System (LMS)

Technologies Used:
- Python
- Django
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- SQLite3

Features:
- Home Page
- About Page
- Courses
- Course Details
- Student Registration
- Student Login
- Dashboard
- Responsive Design

Run Project:

1. Create virtual environment
2. Install requirements
   pip install -r requirements.txt

3. Apply migrations
   python manage.py migrate

4. Run server
   python manage.py runserver

Default URL:
http://127.0.0.1:8000/
